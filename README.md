# GSP AI Manager

Платформа автоматизации для юридической фирмы GSP (Ташкент) — управление делами, канбан, планировщик, аналитика, AI-ассистент с прямым управлением данными, генератор юридических документов, рейтинг и назначение адвокатов (GSP AI Manager), Harvey AI Core (цифровой двойник управляющего партнёра), интеграции с Notion и Telegram.

## Запуск

Открыть `lexai-platform.html` в браузере — это самодостаточный HTML-файл, сервер не требуется.

## AI-функции

Для работы AI Ассистента, генератора документов и Movie Skill нужен бесплатный API-ключ одного из провайдеров (настраивается в разделе «Настройки» внутри платформы):

- [Groq](https://console.groq.com/keys) (Llama 3.3 70B) — бесплатно
- [OpenRouter](https://openrouter.ai/keys) (Claude Sonnet 4)
- [Google Gemini](https://aistudio.google.com/apikey)

Ключ хранится только в localStorage браузера — никуда не отправляется, кроме выбранного AI-провайдера.

## Загрузка документов дела

Поддерживается загрузка PDF, DOCX и TXT — как в AI-чат (для разового анализа), так и в карточку конкретного дела (документ сохраняется при деле и доступен AI при последующих запросах). Извлечение текста работает на стороне браузера через pdf.js и mammoth.js — файлы никуда не отправляются.

## База знаний

`GSP_Notion_Workspace.md` — структура и содержимое базы знаний фирмы (стандарты SAT №1/№2, шаблоны документов, онбординг), которую платформа использует как основу для AI-промптов.
